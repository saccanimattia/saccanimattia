# Mattia Saccani
**Fullstack Software Engineer** | Reggio Emilia, Italy

Software engineer focused on building robust web applications, high-performance APIs, and complex frontend architectures. Currently working at [Ventie30](https://www.ventie30.it/) while pursuing a degree in Computer Engineering at UNIPR. I specialize in designing end-to-end solutions, bridging the modern JavaScript/TypeScript ecosystem with Python for RAG (Retrieval-Augmented Generation) applications and PHP for heavy batch processing and scalable platforms.

## 🏗️ Engineering Focus & Key Implementations

My work spans the entire stack, from provisioning cloud infrastructure to crafting highly interactive client-side components. Key areas of expertise include:

*   **AI Integration & RAG Architectures:** Engineered backend services for AI-driven fraud detection systems and integrated LLM chatbots into secure environments, leveraging vector databases (`pgvector`) and modern Python tooling (`uv`, `FastAPI`).
*   **High-Throughput Backend Processing:** Built resilient data pipelines for massive product batch imports and engineered highly scalable REST/GraphQL APIs utilizing Node.js, Fastify, and Laravel.
*   **Modern Frontend Development:** Architected dynamic, highly responsive client-side applications using React, Next.js, and HTMX, focusing on complex state management and optimized user experiences.
*   **Cloud Infrastructure & IaC:** Leveraged AWS to build robust, cloud-native applications, utilizing AWS CDK for Infrastructure-as-Code and services like SES for reliable transactional communication.
